Science Discovery

探索研究问题，推进科学发现。

把研究问题、数据、方法、计算和证据放进同一个工作空间。你描述目标，它做定向探索、给出计划、调用真实工具跑出结果，并把每个结论连回产生它的那次执行。数据默认全部留在本机。

下载 Windows 安装版 其他平台

安装版支持应用内更新。当前版本 1.1.8，2026-10-16。不需要先装终端、前端或后端。

一次研究怎么走完

和聊天框的差别

结果要能回到那一次执行。

01

结果来自真实执行，不是模型口述。

PLINK2、GCTA、HIBLUP、Beagle 这些工具是真的被调用的。产物落在磁盘上，带着输入摘要、命令、版本和参数。智能体跑命令用应用自带的 Python 3.13，不碰你自己的 Python 环境。

02

领域是数据，不是代码。

一门科学通过科学包接入，带上自己的能力、方法、数据源和确定性检查器，内核一行不改。没选中的包，智能体只知道它已安装，不带上它的能力清单。

03

证据可回溯。

Claim、Citation、Execution、Artifact 是一等对象。交付前会说清查过什么、还有什么没能查。四个容易猜错的参数必须显式声明：矩阵行列方向、基因组坐标系、参考基因组版本、遗传密码表。

科学包

领域换成一份声明，不改内核。

1.1.8 的技能是完整版，共 278 个，标题为中文。科学包页分成通用工作包、科学发现包和自定义包。下面是当前随包的领域，不是客户名单，也不是“对应软件已经装好”的承诺。没有类型化能力的包只提供方法说明、知识库或连接器目录。

生物育种

breeding

质控、LD pruning、PCA、ROH、MLMA-LOCO、多性状评估、GBLUP、基因型填充。

生物信息学

bioinformatics

序列摘要、VCF 变异摘要、阅读框与 ORF、区间与坐标系审计、读段质量剖面。

化学信息学

chemistry-informatics

SMILES 清点、分子式精确质量、成药性规则、反应式原子与电荷守恒。

临床研究

clinical-research

队列表格、Kaplan-Meier 与 log-rank、诊断准确性、基线特征表。研究工具，不提供诊疗建议。

多组学

multi-omics

样本连接审计、表达矩阵质控、差异丰度、批次混杂、通路过表征。

科研方法论

research-methodology

研究设计完整性、统计效能与样本量、多重比较、报告规范条目。

通用统计

statistics

描述统计、组间假设检验与前提诊断、相关分析与多重比较校正。

地球科学

earth-science

再分析、站点观测和格点场各自能支持什么。带阅读笔记，不含数据集本体。

神经科学

neuroscience

记录、成像和脑区主张各自需要什么证据。不含图谱文件。

材料科学

materials-science

区分结构、计算性质和测量性质。不含晶体数据库。

物理 / 数学

physics · mathematics

单位、模型假设、有效数字；证明、符号结果和浮点计算各自能支持的主张。

飞书与实验台

feishu · lab-automation

飞书随包内置。自主实验台目前接的是 LabMCP 仿真器，工具面与真机一致，不是已经连上实验室仪器。

下载与安装

选一个双击。升级由应用自己完成。

模型要自己接

桌面默认使用本机 Codex 登录，不会把登录状态复制进安装包。没有的话，在「设置 · 模型」里添加第三方服务商。

知识库不随包

安装包只带几份领域阅读笔记。专业语料在「知识库」页导入，存在用户数据目录，升级不会覆盖。

工具按需下载

PLINK、GCTA，以及 Linux 上的 HIBLUP 和智能体运行时，用到时在界面里下载，不把所有平台的工具都打进每一个安装包。

平台文件说明
Windows安装版 · 便携版安装版可在应用内替换并重启。便携版不能替换自己，更新时改为下载安装包。
Linux x86_64AppImage · debAppImage 需 chmod +x。安装后的升级走同一个公开更新源，支持断点续传和 sha512 校验。
macOS 13+ Apple Silicondmg拖进「应用程序」。当前未签名未公证，首次打开需在「系统设置 → 隐私与安全性」中放行。

全部文件也在 GitHub v1.1.8。中心更新源不需要内网。数据目录：macOS ~/Library/Application Support/DuanyanScienceDiscovery/，Linux ~/.config/DuanyanScienceDiscovery/，Windows %APPDATA%\DuanyanScienceDiscovery\。
