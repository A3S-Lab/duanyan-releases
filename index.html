跑几天也不用盯着

写下目标和完成标准，端砚一轮接一轮推进直到做完。服务器上的长任务结束或失败时，它会回到原来的对话接着处理。

本机、集群、实验台，一线贯通

分析在本机，计算上集群，测量交给仪器，结果再回到本机进入下一轮。端砚把整个闭环接进同一个任务，数据和记录一路跟着走。

本机

数据、文献和知识库都在自己电脑上。Python、R、PLINK 等软件按需下载，也能放进容器里跑。

服务器与集群

读取 SSH 配置，作业交给 Slurm，GPU 和内存占用看得见；对象存储里的数据按需取进任务。

实验仪器

天平、移液机器人、光谱仪等 32 台设备，按计划逐步调用完成配液和测量，每次调用都有记录。

常见问题

装好之后怎么开始？

在「设置 · 模型」添加一个模型服务，选一个工作文件夹，上传数据后直接描述你的问题。详细步骤见用户手册的「快速开始」。

能用哪些模型？

可以填 DeepSeek、OpenAI、阿里云百炼、智谱、Kimi 等服务商的 API Key，也可以接自己部署的兼容接口；本机已登录的 Codex、Claude Code 可以直接添加，不用填 Key。执行任务的内核可以在 Codex、Claude Code、Pi 之间切换。

我的数据会传到哪里？

工作文件保存在本机。用远程模型、在线检索或外部服务时，相关内容会发给你配置的服务。处理敏感数据前，请先确认单位的要求。

需要会写代码吗？

不需要。用中文描述分析目标即可，端砚会自己写代码并运行；想看或修改代码，工作区里都有。

怎么更新？

安装版在「设置 · 关于」检查更新；便携版回到这里下载新版。
