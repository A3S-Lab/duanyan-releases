## 能做什么

- **数据分析**：在本机读数据、写代码、出图，Python、R、PLINK 等软件按需安装
- **远程算力**：读取 SSH 配置，把作业交给服务器或 Slurm 集群，跑完结果回到对话
- **自主实验台**：天平、移液机器人、光谱仪等 32 台设备，支持 SCPI / Modbus / EPICS / SiLA2
- **科学包**：12 个领域、278 个技能、38 个 MCP 服务，覆盖生物育种、生物信息、化学、材料、物理等
- **可溯源**：回答里的论断连着原文、运行记录和结果文件

## 下载

在 [Releases](https://github.com/A3S-Lab/duanyan-releases/releases/latest) 页面选择对应平台的安装包：

| 平台 | 安装包 |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` |
| Windows x64 | `Setup-…-x64.exe`（安装版）或 `Portable-…-x64.exe`（免安装） |
| Linux x86_64 | `.AppImage` 或 `.deb` |

安装后可在「设置 → 检查更新」中自动更新。

主页的版本号、更新内容、平台可用版本和下载链接由 GitHub Actions 在每次 Release
发布后自动刷新；即使发版时没有手工改网页，下一次打开主页也会显示最新版本。
